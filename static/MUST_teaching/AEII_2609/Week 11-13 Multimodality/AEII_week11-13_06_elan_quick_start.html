Advanced English II (BFE19013)

ELAN: Creating Projects, Tiers, and Annotations

Instructor: Miao Zhang 張淼

Can you find exactly the same movement?

“The speaker moves a hand somewhere around here.”

How could another analyst check that observation?

ELAN lets us attach text to precise time intervals in audio and video: what was said, what moved, and when.

Companion to the first ELAN workshop, after the two introductory multimodality meetings; not an additional three-hour meeting. Demonstrate one operation, then allow students to reproduce it on authorized local media. Protect the save/reopen check. Outcomes: create a reopenable project, add independent tiers, select intervals, create/edit annotations, and navigate between them. Evidence is successful operation on a short recording, not watching the demo.

Primary source: Tacchetti (2018), local ELAN User Guide, version 5.0.0, Introduction and Chapters 1-4. Cross-checked against the official online manual on 18 November 2026 for editing and navigation. The old guide and online manual disagree about Escape in the inline editor: teach the named Commit Changes command, not Escape. Verify menu wording on classroom machines.

Create an ELAN project

What files do we need?

File Job
Media (.mp4, .wav, etc.) The recording
.eaf Annotations, tiers, time boundaries, and links to media
.etf (optional) A reusable tier setup, without recording-specific annotations

The .eaf does not contain the video. Annotating does not change the media.

Tacchetti (2018), Introduction, Chapter 1, and section 3.5. A .pfsx preferences file may also appear; it is not the annotation data.

Prepare the recording

  1. Make a project folder, for example debate_01
  2. Put the authorized local video inside it
  3. Keep the filename stable; check that the file plays
  4. Open ELAN

For this workshop, use a local recording — not a YouTube watch-page link. Keep student recordings in approved course storage.

Use a continuous short passage with audible speech and visible action. A local public-video copy is not evidence of permission to redistribute it. Use the consented instructor-recording fallback where necessary.

New project: choose the media

  1. Select File → New
  2. Browse to your project folder in the New Transcription dialog
  3. Double-click the video filename, or select it and click >>
  4. Check that the file appears in the selected-files panel on the right
  5. Click OK

If the file is hidden, check the dialog’s file-format filter.

Tacchetti (2018), pp. 7-8; online manual, “Creating a new document”: https://www.mpi.nl/tools/elan/docs/manual/Sec_Creating_a_new_document.html Leave the optional Template choice unused for this first walkthrough. Do not instruct students to open the video before choosing File > New.

Check playback, then save

  1. Work in Options → Annotation Mode
  2. Click Play/Pause; check both the picture and sound
  3. Select File → Save As
  4. Save debate_01.eaf in the same folder as the video

Use File → Save regularly as you work.

Annotation Mode is the default general-purpose mode in the local guide. If playback fails, resolve the media problem before annotation. A waveform is not required: the timeline is enough for the selection operations below. Saving: https://www.mpi.nl/tools/elan/docs/manual/Sec_Saving_a_document.html

Find your way around

The parts you will use most

Area What it does
Video Shows the action at the current time
Media controls Play, pause, step forward/backward
Time ruler Shows where you are in the recording
Tier names (left) Identify each annotation stream
Timeline rows Hold annotation boxes along the time axis

Time runs left to right. Each row can describe a different stream.

Three things that are not the same

Item Meaning How to recognize it
Playhead / crosshair One instant Vertical line
Time selection An interval with a beginning and end Shaded region
Active annotation An existing annotation you are working on Outlined annotation box

Selecting time does not create an annotation.

The manual describes light-blue selections and a dark-blue active-annotation frame, but colors can differ by preferences. Emphasize region vs box, not color. https://www.mpi.nl/tools/elan/docs/manual/Sec_The_Timeline_Viewer_and_the_Interlinear_Viewer.html

Move through the recording

  • Click a time in the time ruler to move the playhead there
  • Use Play/Pause for ordinary playback
  • Use previous/next frame controls near a movement boundary
  • In the Controls tab, lower the Rate to slow playback
  • Restore normal speed to hear the surrounding talk

Hover over a control to identify its function before using it.

Tacchetti (2018), sections 2.1-2.2. Demonstrate media controls separately from annotation controls: next frame is not next annotation. Frame duration depends on the recording; do not present a fixed frame duration as universal. https://www.mpi.nl/tools/elan/docs/manual/Sec_The_Media_Player_options.html

Add tiers

A tier and its type do different jobs

A tier is a row of annotations, such as A_speech. A tier type sets the row’s structural rules.

For our first project:

  • Stereotype / constraint: None
  • Time-alignable: yes — annotations have their own start/end times
  • Parent tier: none — independent of other tiers

First create the tier type

  1. Select Type → Add New Tier Type
  2. Enter a name, for example independent
  3. Set Stereotype to None
  4. Leave Controlled Vocabulary as None for now
  5. Click Add, then Close

Time-alignable follows the stereotype; it is not a separate switch to force on.

Tacchetti (2018), p. 18. Some releases use “linguistic type” terminology. Do not create a new type for every row when the same structural rules apply. https://www.mpi.nl/tools/elan/docs/manual/Sec_Adding_new_tier_types.html

Now add the first tier

  1. Select Tier → Add New Tier
  2. Enter Tier name: A_speech
  3. Enter Participant: A
  4. Set Parent tier: none and Tier type: independent
  5. Click Add, then close the dialog

Look for A_speech on the left of the timeline.

Tacchetti (2018), p. 17; the tier name must be unique. Participant A is a stable pseudonymous label, not a guess about identity. If a default tier already contains useful work, rename it through its tier-name context menu > Change Attributes rather than deleting its annotations. https://www.mpi.nl/tools/elan/docs/manual/Sec_Adding_new_tiers.html

Add the other streams the same way

Tier name Participant What belongs here
A_speech A A’s words
B_speech B B’s words
A_RH_form A Right-hand shape, orientation, location, movement

Reuse type independent and parent none for all three.

RH = the participant’s right hand, not screen-right.

Begin with speech and visible form, not a large gesture-code taxonomy. Add A_RH_phase later only if phase analysis is needed; use the same independent type and the phase vocabulary established in the gesture-in-time deck. Keep any default empty tier out of the workflow to avoid unexplained duplication.

Why must these streams be independent?

The hand starts moving before speech and remains raised after speech stops.

What would be lost if its annotation had to fit inside the speech interval?

Across tiers: annotations can overlap.

Within one tier: annotations cannot overlap. Put overlapping speakers on separate speech tiers.

A time-alignable child tier is constrained by its parent; independence avoids forcing hand movement into speech boundaries. This is a minimal course design, not a claim that dependent tiers are never useful.

Select an interval

Choose the active tier

  1. Find A_speech in the tier-name panel on the left
  2. Double-click the tier name
  3. Check that its name is marked as the active tier

The active tier is the target of active-tier annotation commands.

Tier name = the row. Annotation box = one item on that row.

Tacchetti (2018), p. 24: the active tier name is underlined, red, and bold in the guide’s interface. Check local appearance. Changing the active tier does not move existing annotations onto it.

Select with the mouse

  1. Pause playback
  2. Leave Selection Mode off for this first method
  3. In the Timeline Viewer, press at the intended start time
  4. Hold the mouse button and drag to the end time
  5. Release; check the shaded interval and displayed begin/end times

For example: select 00:02.000–00:03.200, not just one point.

Use an empty part of the timeline rather than dragging an annotation box. The demonstration times are instructor-created, not a claim about course media. Tacchetti (2018), section 2.3: https://www.mpi.nl/tools/elan/docs/manual/Sec_Making_a_selection_on_an_independent_tier.html

Another way: click, then Shift-click

  1. Click Clear Selection if an old selection is still present
  2. Click the intended start time to position the playhead
  3. Hold Shift and click the intended end time
  4. Release Shift; check the highlighted interval

With an existing selection, Shift-click can change its extent.

Clear Selection removes the time highlight — not annotations.

Teach the named Clear Selection control rather than a key combination: the online manual’s shortcut tables are not fully consistent for this action. Tacchetti (2018), sections 2.3-2.4. https://www.mpi.nl/tools/elan/docs/manual/Sec_Deselecting_a_selection.html

Replay only what you selected

  1. Click Play Selection, not ordinary Play
  2. Check whether it starts and stops at the intended events
  3. Turn on Loop Mode for repeated playback of the selection
  4. Turn Loop Mode off when finished

Selection too wide or too narrow? Redraw it and replay.

Default Play Selection shortcut: Shift+Space. Name and demonstrate the corresponding button first. Do not leave looping active during later navigation. Tacchetti (2018), section 2.4; online “The Media Player options”.

Zoom before deciding a boundary

  1. Right-click the timeline and choose Zoom
  2. Use Zoom to Selection to enlarge the selected interval
  3. Step through frames near the beginning and end
  4. Replay at normal speed to check the event in context

Zooming changes the view, not the recording or annotation times.

The timeline zoom slider is an alternative. Do not teach zoom as extra measurement accuracy: blur, occlusion, and ambiguous onset remain limitations. https://www.mpi.nl/tools/elan/docs/manual/Sec_Changing_the_time_zoom.html

Create and revise annotations

Turn a selection into an annotation

  1. Activate A_speech and select the speech interval
  2. Double-click inside the shaded selection on that row
  3. In the inline text box, type the words you hear
  4. Right-click inside the text box → Commit Changes
  5. Check that a labeled annotation box remains; File → Save

Commit finishes the text edit. Save writes the document to disk.

Use an empty interval for the first annotation. On an existing annotation, double-clicking opens that annotation for editing instead. Tacchetti (2018), pp. 24-25; cross-check: https://www.mpi.nl/tools/elan/docs/manual/Sec_Inline_Edit_From_Selection.html Do not teach Escape as commit: the current online instructions use it to cancel.

Add the next annotation

  1. Commit the first text edit
  2. Keep A_speech active
  3. Select the next non-overlapping speech interval
  4. Double-click that selection on the row
  5. Enter the words, commit, and replay

Leave a gap if there is genuinely no speech to annotate. Do not force every moment into a speech box.

Annotate the hand on its own tier

  1. Activate A_RH_form
  2. Select the visible action’s own start and end
  3. Double-click the selection on the hand row
  4. Enter an observable description; commit and save

For example: right index finger traces an arc.

Do not copy the speech boundaries unless the visible evidence supports them.

Instructor-created form description; not a transcript from the practice clip. Keep proposed functions or intentions in the evidence sheet. A hidden hand does not establish “no gesture”. If using A_RH_phase, repeat this operation with established phase labels and independently justified boundaries.

Correct the wording

  1. Double-click an existing annotation box
  2. Edit the text in the inline editor
  3. Right-click inside it and choose Commit Changes
  4. Save the document

To discard the current text edit, use Cancel Changes instead.

Changing the words is different from changing the annotation’s time interval.

Equivalent route: right-click the annotation > Modify annotation value. https://www.mpi.nl/tools/elan/docs/manual/Sec_Modifying_the_content_of_annotations.html https://www.mpi.nl/tools/elan/docs/manual/Sec_Inline_Edit_For_Active_Annotation.html

Correct the start or end time

  1. Commit any text edit, then single-click the annotation
  2. Select the corrected interval on the timeline
  3. Right-click the original annotation
  4. Choose Modify Annotation Time
  5. Replay to check the new boundaries; save

A new selection alone does not retime an existing annotation.

Keep the original annotation active while selecting the replacement interval. Mouse alternative: hold Alt (Option on macOS) and drag an active annotation’s edge. Dragging its middle moves the whole annotation; avoid that when only one boundary needs correction. Demonstrate away from neighboring annotations. https://www.mpi.nl/tools/elan/docs/manual/Sec_Changing_the_boundaries_of_an_existing_selection.html

Switch between annotations

Click to inspect; double-click to edit

Action Use it to…
Single-click an annotation box Make it the active annotation
Double-click an annotation box Open its text editor
Double-click a tier name Make that row active
Drag across time Make a time selection

Before switching, commit or cancel any open text edit.

Ask students to point out the active box and the active row. These are separate from the time selection used for Play Selection. If the selection does not cover the box they want to replay, select its interval explicitly.

Previous and next on the same tier

  1. Activate A_speech and click one of its annotations
  2. Find the Annotation Controls near the playback controls
  3. Click Next Annotation to move forward on that tier
  4. Click Previous Annotation to move back

Check which annotation box is now active.

These are not the next/previous frame media buttons.

Hover over each control during the demonstration. The online manual lists Alt+Right / Alt+Left as default next/previous annotation shortcuts. https://www.mpi.nl/tools/elan/docs/manual/Sec_The_Media_Player_options.html

Switch to another tier’s annotation

  • Direct route: single-click the desired box on A_RH_form
  • Control route: use Annotation Above / Annotation Below
  • To create new hand annotations, activate the hand tier name first

Independent tiers may have different numbers of annotations and gaps. Check the selected box rather than assuming a one-to-one match.

Above/below navigation targets an annotation on a neighboring tier; do not promise a corresponding gesture for each utterance. Default Alt+Up / Alt+Down. Keep the mouse route available if no appropriate annotation is reached. Ask what the hand does before, during, and after the selected speech.

Optional keyboard shortcuts

Action Manual’s default
Play selected interval Shift + Space
Previous / next annotation Alt + Left / Right
Annotation above / below Alt + Up / Down
Commit text in the inline editor Ctrl + Enter

Check Edit → Preferences → Edit Shortcuts for your installation. On macOS, Alt is Option; many Ctrl shortcuts use Command instead.

Shortcuts depend on platform, mode, preferences, and focus. Commit the editor before using navigation keys. Do not assume every Ctrl shortcut converts to Command on macOS. Named buttons/context commands above remain the primary route. https://www.mpi.nl/tools/elan/docs/manual/Sec_Editing_Shortcuts.html https://www.mpi.nl/tools/elan/docs/manual/Sec_The_shortcut_keys.html

Can you inspect the same action twice?

Find an annotation, move to the next one, then return.

  • Is the original box active again?
  • Can you replay only its interval?
  • Can you switch to the hand tier and inspect the overlapping action?
  • Do the speech and hand boundaries really match?

Use the actual practice recording, without assuming the hand overlaps every speech segment. This checks navigation and selection rather than terminology recall. If necessary, redraw the desired playback interval before Play Selection.

Keep the project usable

Save, close, reopen

  1. Commit the last text edit; choose File → Save
  2. Close the document
  3. Choose File → Open and select debate_01.eaf
  4. Check the tiers and annotations
  5. Play the media and replay one annotation interval

New starts from a new recording. Open resumes an existing .eaf.

If something does not work

Problem Check
New tier is unavailable Was its type added? Is the parent set to none?
Cannot create an annotation Correct row? Non-zero selection? Existing box in the way?
Wrong passage plays Check the selection; use Play Selection
New selection did not change a box Use Modify Annotation Time
Video missing after reopening Check the media path; repair it in Edit → Linked Files

Do not relink an annotated project to a different recording. Link repair is for the same media that has moved, not transferring old annotations to new data. Save and test again after repairing a media link. https://www.mpi.nl/tools/elan/docs/manual/Sec_Changing_the_links_to_media_files.html Surface playback/install problems and resolve them on the classroom machine; do not treat a silent or blank video as a successful project.

Reuse the setup, not the old annotations

  1. In the configured project, choose File → Save as Template
  2. Save multimodal_basic.etf
  3. For another recording, choose File → New
  4. Add the new media and choose the .etf under Template
  5. Save a new .eaf for that recording

An .etf reuses the tier design, not the previous recording’s annotations.

Tacchetti (2018), p. 23. https://www.mpi.nl/tools/elan/docs/manual/Sec_Saving_a_template.html This is optional after the basic project and navigation workflow succeeds.
